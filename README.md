# VELOCE — متجر ملابس رياضية

موقع متجر إلكتروني كامل لملابس رياضية، مبني بـ HTML/CSS/JavaScript عادي (بدون أي إطار عمل)،
مع تسجيل دخول وتسجيل حسابات، لوحة تحكم أدمن، انتقالات ثلاثية الأبعاد بين الصفحات باستخدام
**Three.js**، وقاعدة بيانات/مصادقة عبر **Supabase**.

## بنية المشروع

```
sportswear-store/
├── index.html          الصفحة الرئيسية (Hero ثلاثي الأبعاد + منتجات مميزة)
├── shop.html            صفحة المتجر مع فلاتر التصنيف والترتيب
├── product.html          صفحة تفاصيل المنتج (مقاسات، ألوان، إضافة للسلة)
├── checkout.html         إتمام الشراء وإنشاء الطلب في Supabase
├── login.html            تسجيل الدخول
├── register.html         إنشاء حساب جديد
├── admin.html            لوحة تحكم الأدمن (محمية)
├── css/style.css         نظام التصميم الكامل
├── js/
│   ├── supabase-client.js  إعداد الاتصال بـ Supabase
│   ├── cart.js             منطق سلة المشتريات (localStorage)
│   ├── three-hero.js        المشهد ثلاثي الأبعاد في الصفحة الرئيسية
│   ├── three-auth.js        المشهد ثلاثي الأبعاد في صفحات الدخول/التسجيل
│   ├── three-transition.js  تأثير الانتقال ثلاثي الأبعاد بين الصفحات
│   └── admin.js             منطق لوحة تحكم الأدمن (CRUD)
└── vendor/
    ├── three.min.js         مكتبة Three.js (مضمّنة محلياً)
    └── supabase.js          مكتبة @supabase/supabase-js (مضمّنة محلياً)
```

## قاعدة بيانات Supabase

تم إنشاء مشروع Supabase جديد وربطه مباشرة بالموقع (البيانات موجودة في
`js/supabase-client.js`). الجداول التي تم إنشاؤها تلقائياً:

- **profiles** — بيانات المستخدم + الصلاحية (`customer` أو `admin`)، تُنشأ تلقائياً عند التسجيل.
- **categories** — تصنيفات المنتجات (تدريب، جري، كرة قدم، إكسسوارات).
- **products** — المنتجات (اسم، سعر، صور، مقاسات، ألوان، مخزون...).
- **orders** / **order_items** — الطلبات وعناصرها.

تم تفعيل **Row Level Security** على كل الجداول:
- أي زائر يقدر يشوف المنتجات والتصنيفات.
- المستخدم يشوف طلباته الخاصة فقط.
- الأدمن فقط يقدر يضيف/يعدّل/يحذف منتجات وتصنيفات، ويشوف كل الطلبات.

تم إضافة 8 منتجات تجريبية و4 تصنيفات كبيانات أولية حتى يظهر المتجر جاهزاً من أول مرة.

## كيف تخلي حساب معين "أدمن"

النظام لا يسمح لأي حد يسجل كأدمن من الفورم مباشرة (لحماية الموقع). لازم ترفع صلاحية
المستخدم يدوياً من لوحة Supabase:

1. سجّل حساب عادي من صفحة `register.html`.
2. من [لوحة Supabase](https://supabase.com/dashboard/project/lnivpzzdnorobkaxvwdl) افتح
   **SQL Editor** ونفّذ:

   ```sql
   update public.profiles
   set role = 'admin'
   where id = (select id from auth.users where email = 'admin@example.com');
   ```

   (غيّر الإيميل بإيميل الحساب اللي عايز تخليه أدمن).
3. سجّل خروج ودخول تاني — هيتوجه تلقائياً لصفحة `admin.html`.

## تشغيل الموقع محلياً

الموقع HTML/CSS/JS عادي بدون أي build step. أسهل طريقة لتشغيله محلياً (لتفادي مشاكل CORS
مع فتح الملفات مباشرة):

```bash
cd sportswear-store
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080` في المتصفح.

## النشر (Hosting)

الموقع static بالكامل، فتقدر ترفعه مباشرة على أي من:
- **Netlify** أو **Vercel** (اسحب المجلد وارفعه، أو اربطه بـ Git).
- **GitHub Pages**.
- أي استضافة عادية (Hostinger, cPanel...) — فقط ارفع كل الملفات كما هي.

## الانتقالات ثلاثية الأبعاد (Three.js)

- `three-transition.js`: تأثير "مسارات جري" يغطي الشاشة بخطوط مائلة متحركة عند الانتقال بين
  أي صفحتين (عبر إضافة `data-transition` لأي رابط `<a>`)، ثم يُكشف تدريجياً في الصفحة الجديدة.
- `three-hero.js`: شكل ثلاثي الأبعاد متحرك (Torus Knot) بألوان الهوية، يتفاعل مع حركة الماوس.
- `three-auth.js`: مجسم متعدد الأوجه دوّار في خلفية صفحتي الدخول والتسجيل.
